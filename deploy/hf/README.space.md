# Orbit Helpdesk: live demo

An AI agent for an internal IT & HR helpdesk, with a fictional company and synthetic data.
To keep the demo free it uses a rule-based stand-in instead of a language model, and a built-in mock ticket system instead of n8n.

Code, architecture and eval results: https://github.com/ZoePetro0510/helpdesk-ai
