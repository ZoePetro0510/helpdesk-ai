# Software and Licenses

## Installing approved software
Approved software can be installed without admin rights from the Self Service app (macOS) or the Company Portal app (Windows). This includes Slack, Zoom, Visual Studio Code, Figma, Postman, Docker Desktop and the Microsoft Office suite.

## Requesting software that is not in the catalog
Open a helpdesk request with the software name, the business reason and whether it needs a paid license. Security reviews new software within 5 working days. Free tools that store company data in the cloud also require a security review.

## Paid licenses
Paid licenses such as Adobe Creative Cloud, JetBrains IDEs or Tableau need manager approval and are charged to your team's budget. Licenses that are unused for 60 days are reclaimed automatically.

## AI tools
Employees may use the company's approved AI assistant with company data. Pasting customer data, source code or employee information into other public AI tools is not allowed.
